The split is simple: the agent does the boring stuff, I do the hard stuff. But "boring" doesn't mean unimportant — it means *mechanical*. Stuff that takes time and attention but not judgment.

## The Split

| The agent does (boring) | I do (hard) |
|-------------------------|-------------|
| Scaffold templates, write boilerplate | Design the architecture |
| Migrate content between formats | Decide what the content should say |
| Trace through source code for debugging | Identify *what* to debug |
| Run tests, check compatibility | Decide what to test |
| Write conventional commits | Decide when to commit |

The pattern: **attention is the scarce resource, not code.**
