A command-line interface for the [Kite Connect](https://kite.trade) trading API with three interaction modes: traditional CLI commands, an interactive TUI, and a pipe mode for scripting and automation.

## Features

- **Portfolio** — view holdings, positions, and order history with P&L
- **Trading** — place, modify, and cancel orders with dry-run support
- **Interactive TUI** — full-screen interface with tabbed navigation and live refresh
- **WebSocket ticker** — stream real-time market data
- **Pipe mode** — JSON output for automation and agent integration
- **Secure auth** — OAuth flow with credential storage
